# 축3 — 자본거래·상속·증여·가업승계

## 1. 증여재산공제 (10년 누적)

| 관계 | 공제 |
|---|---|
| 배우자 | 6억 |
| 직계존속→비속 성년 | 5,000만 |
| 직계존속→비속 미성년 | 2,000만 |
| 직계비속→존속 | 5,000만 |
| 기타 친족 (6촌 혈족·4촌 인척) | 1,000만 |
| **혼인공제** (혼인 전후 2년) | +1억 (직계존속만) |
| **출산공제** (출산·입양 2년) | +1억 (혼인공제와 통합 1억 한도) |

## 2. 상속세 (상증법)

| 구분 | 한도 |
|---|---|
| 일괄공제 | 5억 (인적공제·기초공제 합산보다 큰 경우) |
| 배우자공제 | 최소 5억 ~ 최대 30억 |
| 자녀공제 | 1인당 5,000만 (현행) |
| 동거주택상속공제 | 6억 |

**세율**: 5단계 누진, 최고 50% (30억 초과). 최대주주 할증 20% (중소 제외)

**유산취득세 전환**: 2025.3.12 정부안 발표 → **2028.1.1 시행 목표**. 자녀공제 1인당 5억으로 인상, 최고세율 40%로 인하 검토 [확신 90]

**신고기한**: 상속개시일 속한 달 말일로부터 **6개월** (해외거주 9개월)

## 3. 가업상속공제 (상증법 §18의2)

| 사업영위 기간 | 공제 한도 |
|---|---|
| 10~20년 | 300억 |
| 20~30년 | 400억 |
| 30년 이상 | **600억** [확신 90] |

**사후관리 5년**: 가업자산 40% 이상 처분 금지·1년 이상 휴폐업·주업종 변경 금지·정규직 고용·총급여 90% 유지

## 4. 가업승계 증여세 과세특례 (조특법 §30의6)

- 600억 한도, 10억 공제 후
- **120억 이하 10% / 초과분 20%** (2026.1.1 시행) [확신 90]
- 사후관리 7년

## 5. 부담부증여

- 채무 인수액만큼 증여세 과세가액 차감 + 증여자에게 양도세
- 전세보증금·근저당 채무를 수증자가 인수하는 구조
- **함정**: 시세차익 큰 부동산은 오히려 양도세 부담 ↑
- 시세차익 적은 부동산일수록 유리

## 6. 명의신탁 증여의제 (상증법 §45의2)

- 실소유자→명의자 증여 의제
- 조세회피목적 추정·납세자 입증책임
- 부당무신고가산세 40% 부과 ✗ (사기·기타 부정행위 아님) → 일반 무신고가산세 20%만
- **명의신탁주식 실소유자 확인제도** (국세청): 2001.7.23 이전 설립 + 중소기업 + 실소유자·명의수탁자 모두 발기인

## 7. 일감몰아주기 (상증법 §45의3) / 일감떼어주기 (§45의4)

- 특수관계법인 매출비중 + 지분율 조건 충족 시 지배주주·친족 과세
- 떼어주기: 2015.12.15 신설, 사업기회 제공 이익 과세
- 신고기한: 6.30

## 8. 세대생략 (상증법 §57)

- 직계비속 손자녀 직접 증여 → 산출세액 **30% 할증**
- 미성년 + 20억 초과 → **40% 할증**
- 1세대 건너뛰면 1회분 상속·증여세 절감

## 9. 사전증여 합산 (상증법 §13)

- 상속개시 전 10년 이내 상속인 증여재산 합산
- 5년 이내 비상속인 증여재산 합산
- → 60대 이전 분산증여로 10년 룰 벗어나기

## 10. 보험금 증여 구조

- 계약자·수익자 분리 시 보험금 수령 시점 증여 발생
- 계약자=납입자=수익자 통일 시 증여세 회피
- 장애인 수익자 매년 4,000만 비과세

## 11. 가족간 매매 (시가 95~105% 안전구간)

- **양도세 부당행위계산 부인**: 시가의 **5% 또는 3억 중 적은 금액** 차이 시 시가로 재계산
- **증여세 추정**: 시가의 **30% 또는 3억 중 적은 금액** 차이 시 차액을 증여로 봄
- 양도자에 엄격 / 양수자에 관대

## 12. 신탁 활용

- **유언대용신탁** (신탁법 §59): 상속재산 포함 (2021~). 절세효과 X, 유류분 회피·집행 편의용
- **수익자연속신탁** (§60): 위탁자→배우자→자녀→손자. 각 단계 상속세 부과 (이중과세 조정)

## 13. 해외 거주 자녀 증여

- 거주자→비거주자 증여: 증여자가 신고·납부 의무
- 비거주자 수증재산: **국내재산만 과세**, 국외재산 비과세
- → 국외재산 사전이전 절세 가능

## 절세 시나리오 10+ (사전증여 시점 설계 중심)

1. 60대 초반 사전증여 (가업승계 과세특례 10%) — 자녀 경영 안착 확인 후
2. 70대 이상 → 가업상속공제 활용 (사후관리 5년)
3. 혼인·출산공제 활용 — 자녀 2년 내 1억 추가
4. 차명주식 환원 — 실소유자 확인제도 활용
5. 부담부증여 — 채무 인수로 과세가액 축소 (시세차익 적은 자산)
6. 세대생략 30% 할증 + 1세대 상속세 절약 (손자녀 자산가치 ↑ 시)
7. 부부 공동명의 vs 1세대1주택 단독 — 종부세 시뮬 비교
8. 보험금 계약자=수익자 통일
9. 유산취득세 시행 전(2028 이전) vs 후 시뮬레이션
10. 해외자녀 국외재산 사전이전
