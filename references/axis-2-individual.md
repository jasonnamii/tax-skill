# 축2 — 소득세·종합소득

## 1. 종합소득세 8단계 누진 (소법 §55)

| 과세표준 | 세율 |
|---|---|
| 1,400만 이하 | 6% |
| 1,400~5,000만 | 15% |
| 5,000~8,800만 | 24% |
| 8,800만~1.5억 | 35% |
| 1.5억~3억 | 38% |
| 3억~5억 | 40% |
| 5억~10억 | 42% |
| 10억 초과 | 45% |

지방소득세 10% 별도 → 최고 실효 **49.5%**

## 2. 금융소득 종합과세 (소법 §14)

- 이자+배당 **2,000만 초과** 시 종합합산
- 2,000만까지: 14% (지방세 포함 15.4%) 분리과세
- **배당소득 분리과세 신설** (2026.1.1~2028.12.31, 3년 한시) [확신 90]
  - 배당성향 40% 이상 또는 25%·전년 대비 10% 증가 기업
  - 2,000만 이하 14% / 2,000만~3억 20% / 3억~50억 25% / 50억 초과 30%
  - ETF·펀드 분배금·REITs 배당 제외

## 3. 금융투자소득세(금투세) — 폐지 확정

- 2024.12.10 폐지 확정, 2025.1.1 시행 [확신 90]
- 증권거래세 0.20% 환원
- 상장주식 대주주(50억 이상) 양도세는 유지: 3억 이하 22% / 3억 초과 27.5%

## 4. 양도소득세 (부동산)

- 기본 누진 6~45% (2년 이상 보유)
- 1년 미만 70%, 1~2년 60% (주택)
- **1세대1주택 12억 초과분만 과세** + 장기보유특별공제표:
  - 보유 4%/년 (최대 40%) + 거주 4%/년 (최대 40%) = 합산 80%
- **다주택 중과 부활 2026.5.10** [확신 90]
  - 2주택자: 기본세율 + 20%p
  - 3주택 이상: 기본세율 + 30%p
  - 장특공 배제
- 일시적 2주택 비과세: 종전 취득 후 1년 + 종전 2년 보유 + 신규 취득 후 **3년 내** 종전 양도

## 5. 가상자산 과세

- **2027.1.1로 재유예 (3차)** [확신 90]
- 시행 시: 기타소득 250만 초과분 22%
- 2026.12.31 시가와 취득가 중 큰 금액 = 의제취득가

## 6. 사업소득

| 구분 | 신규/직전 수입 | 미적용 시 |
|---|---|---|
| 단순경비율 | 신규 또는 일정 이하 | 의제 경비 |
| 기준경비율 | 그 외 무기장 | 주요경비 증빙 |
| 복식부기 의무 | 농업·도매·소매·부동산매매 3억↑ / 제조·숙박·음식 1.5억↑ / 부동산임대·교육 7,500만↑ | 무기장가산세 20% |

기장세액공제: 간편장부 대상자가 복식부기 시 **20%** (연 100만 한도)

## 7. 성실신고확인대상자 (소법 §70의2)

| 업종 | 매출 기준 |
|---|---|
| 농업·도매·소매·부동산매매·광업 | 15억 |
| 제조·숙박·음식·건설·운수·금융·전기가스 | 7.5억 |
| 부동산임대·교육·보건·전문서비스·개인서비스 | 5억 |

- 세액공제: **120만** (2024년 60만→120만 상향, 조특법 §126의6)

## 8. 종합소득세 세액공제·감면

- **자녀세액공제** (2026~): 1자녀 25만, 2자녀 합 55만, 3자녀 이상 더 확대 [확신 90]
- **자녀장려금**: 18세 미만 자녀당 50~100만
- **결혼세액공제**: 2024~2026 한시, 1인 50만, 부부합 최대 100만 [확신 90]
- **출산·보육수당 비과세**: 월 10만 → **20만** (자녀당) [확신 90]
- 연금저축·IRP: 최대 900만 한도, 5,500만 이하 16.5% / 초과 13.2%
- ISA: 일반 200만/서민 400만 비과세, 초과분 9.9% 분리
