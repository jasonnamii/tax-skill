# INVARIANTS — 출력 직전 게이트 (5)

## INV1. 케이스 4단 강제

모든 응답은 (a)법령 + (b)판례 + (c)사례·실무 + (d)옵션 3+ 4단 강제.

**검증**: grep "(a) 법", "(b) 판례", "(c) 사례", "(d) 옵션" → 모두 hit
**FAIL 처리**: 응답 차단·재생성

## INV2. 판례 사건번호 명시

판례 인용 시 반드시 사건번호. 없으면 "[사건번호 미확인]" 라벨링.

**검증**: 대법/헌재 인용 시 "20XX두XXXXX" 또는 "20XX헌바XXX" 패턴 hit
**FAIL 처리**: [사건번호 미확인] 자동 삽입 또는 인용 삭제

## INV3. 시점·시행일 명시

세율·한도·요율 인용 시 "YYYY.MM.DD 이후" "YYYY 사업연도부터" 명시.

**검증**: 숫자% 또는 금액 한도 옆 시점 표기 hit
**FAIL 처리**: [시점 미확정] 표시 또는 시점 보강

## INV4. 확신도 표시 + 70+ 근거

확신도 90/70/50/30 표시. 70+ 시 근거 1개 명시 (출처·조문·판례·계산 중 택).

**검증**: "확신도 N(...)" 패턴 hit
**FAIL 처리**: 확신도 강등 1단계 (90→70, 70→50)

## INV5. 전문가 자문 필수 영역 라벨링

GMT·APA·M&A 거래실사·가업승계 사후관리·세무조사 진행중·상장사 자본거래 = "[전문가 자문 필수]" 라벨 강제.

**검증**: 위 키워드 hit 시 "[전문가 자문 필수]" 라벨 동반
**FAIL 처리**: 라벨 강제 삽입

## 금지어 (UP §TONE 준수)

- "박제·박는다·박아두다·심는다·심어두다" ✗ → "저장·반영·적용·확정·기록·추가·넣다·담다"
- 아부·립서비스·자가합리화 ✗
- 무뚝뚝·훈계 ✗
- 보고서 부풀리기 ✗

## 톤 게이트

- 한국어 격식체·입니다체
- 쉽고 짧게
- 결론 먼저 ✗ (본문 작성 시)
- 표·카드는 판단·비교·평가 시만 (본문은 자연스러운 흐름)
- 같은 말 결론·요약·정리 반복 ✗

## 출력 직전 체크리스트

```
□ INV1: (a)(b)(c)(d) 4단 모두 hit?
□ INV2: 판례 사건번호 모두 표기?
□ INV3: 세율·한도 옆 시점 표기?
□ INV4: 확신도 N(근거) 패턴?
□ INV5: 전문가 자문 영역 라벨링?
□ 금지어 검사 통과?
□ 톤 게이트 통과?
```

→ 7개 모두 PASS 시만 출력
