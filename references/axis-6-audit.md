# 축6 — 세무조사·불복·형사

## 1. 세무조사 종류 (국기법 §81의6)

- **정기조사**: ① 신고성실도 분석 결과 불성실 혐의 ② 4과세기간 이상 미조사 ③ 무작위 표본
- **비정기(수시)조사**: 탈루 혐의 명백, 신고누락 의심, 거래처 혐의 발견 등

## 2. 사전통지 (§81의7)

- 조사개시 **15일 전**까지 통지
- **2026.4부터 정기조사 대상자는 3개월 내 월 단위 착수시기 선택 + 20일 전 정식 사전통지** [확신 90]
- 연기신청 가능 (천재·질병·업무·자료준비) — 7일 내

## 3. 조사기간

- 정기 15~20일, 비정기 60일
- 연장사유 (§81의8): 은닉·제출 지연, 거래처 조사, 탈루 포착, 천재지변

## 4. 납세자 권리 (§81의2~§81의5)

- 조사 입회 및 의견진술권
- **변호사·세무사 등 조력 받을 권리**
- 중복조사 금지 (§81의4). 예외: 새로운 탈루 증거, 거래상대방 조사
- 자료제출 거부권: 영업비밀·헌법상 자기부죄거부

## 5. 부과제척기간 (국기법 §26의2)

| 구분 | 기간 |
|---|---|
| 일반 국세 (법·소·부) | **5년** |
| 무신고 | **7년** (역외 10년) |
| 사기·부정행위 | **10년** (역외 부정 15년) |
| 상속·증여세 | **10년** (부정·미신고·허위 15년) |
| 부정행위 가산세 | **10년** |

## 6. 불복 4단계 (국기법 §55~)

```
[처분]
   ↓ 90일 (선택)
[이의신청] (세무서장·지방국세청장) → 30일 결정
   ↓ 90일
[심사청구] (국세청장)  OR  [심판청구] (조세심판원)  ※중복 ✗
   ↓
[감사원 심사청구] (선택)
   ↓ 결정통지 후 90일
[행정소송] (행정법원 → 고등법원 → 대법원)
```

- **과세전적부심사** (§81의15): 세무조사 결과통지 후 30일 내, 본 처분 전 단계
- **조세심판원 인용률 (100억+)**: 2023년 37.5% → 2024년 42.3%

## 7. 조기경정청구 (§45의2)

- 법정신고기한 후 **5년** 이내
- 후발적 사유 (판결·계약해제·소급적 사정변경): 사유발생일 **3개월** 이내

## 8. 수정신고 가산세 감면 (§48)

| 시점 | 감면율 |
|---|---|
| 1개월 내 | 90% |
| 1~3개월 | 75% |
| 3~6개월 | 50% |
| 6개월~1년 | 30% |
| 1년~1.5년 | 20% |
| 1.5년~2년 | 10% |

납부지연 가산세는 별도, 감면 없음

## 9. 조세범처벌법

| 구분 | 처벌 |
|---|---|
| §3 포탈 (기본) | 2년 이하 또는 포탈세액 2배 이하 벌금 |
| §3 가중 (3억+ & 신고세액 30%+ OR 5억+) | 3년 이하, 3배 이하 |
| §10③ 거짓 세금계산서 | 3년 이하, 공급가액×10%×3배 이하 |
| §10④ 30억 이상 | 가중 |

## 10. 특가법 §8 (조세포탈 가중)

| 연간 포탈세액 | 처벌 |
|---|---|
| 5억~10억 | 3년 이상 유기 + 벌금 병과 |
| 10억 이상 | 무기 또는 5년 이상 + 벌금 병과 |

## 11. PCI 분석 (Property-Consumption-Income)

- = 일정기간(5년) **재산증가액 + 소비액 − 신고소득**
- 차액 임계치 초과 시 자금출처 소명요구 → 미소명 시 증여추정 (상증법 §45)
- 2025~ 빅데이터·AI 분석 자동화

## 12. 자금출처조사·증여추정 배제 기준 (10년 누적)

| 구분 | 30세 미만 | 30세 이상 | 40세 이상 |
|---|---|---|---|
| 주택 취득 | 5,000만 | 1.5억 | 3억 |
| 기타재산 | 5,000만 | 5,000만 | 1억 |
| 채무상환 | 5,000만 | 5,000만 | 5,000만 |

## 13. 디지털 포렌식·CARF

- 디지털 포렌식: 컴퓨터·휴대전화·클라우드 압수 후 삭제데이터 복원
- 국세청 디지털자산국 신설, AI 기반 가상자산 통합분석
- **2026 중점**: ① 지배주주 터널링 ② 주가조작 ③ 유튜버·SNS 호화과시 ④ 부동산 탈세 ⑤ 코인·해외주식

## 14. 통고처분 (조세범처벌절차법)

- 벌금상당액 납부 → 고발 면제
- **특가법 적용 사건(5억+) 제외** — 직접 고발

## 세무조사 D-Day 대응 매뉴얼

### D-15 (사전통지 수령)
- [ ] 변호사·세무사 선임 즉시
- [ ] 쟁점 세목·기간·범위 확인
- [ ] 회계서류·이메일·계약서 백업 (위·변조 금지)
- [ ] 연기신청 가능 사유 검토 (7일 내)

### D-Day (조사 개시)
- [ ] 조사관 신분증·조사명령 사본 확인
- [ ] 입회권 행사 — 모든 면담에 대리인 동석
- [ ] 별도 회의실·자료실 분리

### 조사 중
- [ ] 질문은 서면화 요청 (구두 진술 자제)
- [ ] 자기부죄 우려 진술 거부 (헌법 §12)
- [ ] 매일 종료 후 회의록 작성·교차확인

### 결과통지 수령 (D+0)
- [ ] **30일 내 과세전적부심사** 검토 (본처분 차단)
- [ ] 또는 수정신고 (가산세 감면)

### 처분 후
- [ ] 90일 내 이의신청(임의) → 심사 또는 심판
- [ ] 심판은 조세심판원, 심사는 국세청장 — 일반적으로 **심판청구 인용률 ↑**
- [ ] 행정소송 90일 기한

## 자료제출 거부권 행사 시점

- **거부 가능**: 조사범위 외 자료, 영업비밀로 과세요건 무관, 변호사-의뢰인 통신
- **거부 불가**: 장부·증빙·세금계산서 등 직접 과세요건 자료 (거부 시 추계과세·가산세)
- **실무 기준**: "조사범위 명시 → 범위 내 협조, 범위 외 서면 요청 요구"

## 과세전적부심사 vs 조기경정청구 선택

| 상황 | 선택 |
|---|---|
| 세무조사 결과통지 직후 | 과세전적부심사 (30일 내) |
| 자진 신고 후 오류 발견 | 수정신고 |
| 신고 후 더 낸 세금 환급 | 조기경정청구 (5년) |
| 판결·계약해제 후발적 사유 | 후발적 경정청구 (3개월) |
| 부과처분 후 | 이의→심판→소송 |
