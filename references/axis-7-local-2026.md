# 축7 — 지방세 + 2026 개정세법 총정리

## A. 지방세

### 1. 취득세 (주택)

| 구분 | 일반지역 | 조정대상지역 |
|---|---|---|
| 1주택 | 6억 이하 1% / 6~9억 1~3% 누진 / 9억 초과 3% | 동일 |
| 2주택 | 1~3% | **8%** |
| 3주택 | **8%** | **12%** |
| 4주택 이상·법인 | **12%** | **12%** |
| 비주택 (상가·토지) 유상 | 4% | 동일 |
| 증여 (조정·시가표준 3억+) | 12% | 12% |

- 농어촌특별세 0.2%, 지방교육세 0.1~0.4% 부가
- **신고기한**: 잔금일로부터 60일 (증여 3개월·상속 6개월)

### 2. 생애최초 취득세 감면

- 실거래가 12억 이하 → **200만 한도 전액 면제** (소형주택 300만)
- 소득·연령 요건 폐지

### 3. 재산세 (주택)

| 과세표준 | 세율 |
|---|---|
| 6,000만 이하 | 0.1% |
| 6,000만~1.5억 | 0.15% |
| 1.5억~3억 | 0.25% |
| 3억 초과 | 0.4% |

- 공정시장가액비율 (2026): **60%**

### 4. 종합부동산세 (종부세)

- 기본공제: **1주택자 12억**, **다주택자 9억**, 법인 0원
- 공정시장가액비율: 2025년 45→60% 환원, 2026년 60% 유지 전망
- 세율: 2주택 이하 0.5~2.7%, 3주택 이상(과표 12억+) **0.5~5.0%**
- 부부 공동명의: 12억(1인 6억×2) vs 1세대1주택 단독 12억 중 유리한 방식 선택 (§10의2)
- 일시적 2주택·상속주택·지방 저가주택(공시 3억 이하·수도권 외)은 1주택자 판정 시 주택 수 산정 제외

### 5. 자동차 취득세

- 비영업용 승용 7%, 경차 4%
- 자동차교육세 = 자동차세의 30%

### 6. 지방소득세

- 법인: 법인세액의 10% (별도 신고, 법인세 신고 후 1개월 내)
- 개인: 종합소득세의 10% (합산 시 6.6~49.5%)

## B. 2026 개정세법 핵심 (시행일 순)

### 2026.1.1 시행

| 분야 | 변경 |
|---|---|
| 법인세 | 세율 전 구간 1%p 인상 (10/20/22/25%) |
| 법인세 | 부동산임대 소규모법인 9→19% |
| 법인세 | 거짓세금계산서 가산세 3→4% |
| 법인세 | 기업업무추진비 추가한도 10→20%, 지역사랑상품권 포함 |
| 소득세 | 배당소득 분리과세 신설 (14/20/25/30%, 3년 한시) |
| 소득세 | 자녀세액공제 1인당 10만 인상 |
| 소득세 | 출산·보육수당 비과세 월 10→20만 |
| 양도세 | 가상자산 과세 2027.1.1 재유예 |
| 부가세 | 간이과세 배제지역 64개 신설 |
| 증여세 | 가업승계 과세특례 10% 구간 120억 유지 |
| 국제 | QDMTT 시행 |
| 조특법 | 창업중소기업 세액감면 지역 세분화 (수도권 과밀/비과밀/비수도권+인구감소) |
| 비과세종합저축 | 만 65세 + 기초연금 수급자만 |

### 2026.2.25 시행

- 자사주 1년 내 소각 의무화 (개정 상법)

### 2026.3.10 시행

- 노란봉투법 (노조법 2·3조) — 노동스킬 영역

### 2026.3.20 시행

- 미환류소득 환류비율 60~80% → 65~85%, 배당 공제 추가

### 2026.4 시행

- 정기 세무조사 대상자 — 3개월 내 월 단위 착수시기 선택 + 20일 전 사전통지

### 2026.5.10 시행

- 다주택 양도세 중과 유예 종료 → 조정대상지역 2주택 +20%p / 3주택+ 30%p, 장특공 배제

### 2026.6.30 (1회성)

- GMT 최초 신고기한

### 2028.1.1 (예정)

- 유산취득세 전환 (자녀공제 5억, 최고세율 40%로 인하 검토)

## C. 조정대상지역 현황 (2026.5 기준)

- **서울 25개 자치구 전역** (2025.10.15 신규 21개 추가)
- **경기 12개**: 과천·광명·성남(분당·수정·중원)·수원(영통·장안·팔달)·안양(동안)·용인(수지)·의왕·하남
- 강남·서초·송파·용산: 토지거래허가구역 중첩 (2026년 말까지 연장)

## D. 일시적 2주택 비과세 특례

- 종전주택 취득 후 **1년 경과** 신규 취득
- 종전 **2년 이상 보유** (조정 시 2년 거주)
- 신규 취득일부터 **3년 이내** 종전 양도 (2023.1.12~ 통일)

## E. 임대주택 사업자 세제

- 종부세 합산배제: 건설임대(전용 149㎡↓·공시 9억↓·2호↑), 매입임대(수도권 6억↓·비수도권 3억↓)
- 거주주택 비과세 (시행령 §155⑳): 임대주택 외 1주택 2년 거주 후 양도 시 1세대1주택 비과세. **평생 1회 한정**
- **6년 단기임대제도** (2025.6.4 시행): 비아파트, 의무 6년, 보증보험 의무, 세제혜택 강화

## F. 창업·스타트업 세제 (2026 지역 세분화)

### 청년창업 (만 15~34세, 군복무 6년 차감)

| 지역 | 감면 |
|---|---|
| 비수도권·수도권 인구감소지역 | **100% (5년)** |
| 수도권 비과밀억제권역 | 75% (5년) |
| 수도권 과밀억제권역 | 50% (5년) |

### 일반창업 (수입 4,800만 이하 소기업)

| 지역 | 감면 |
|---|---|
| 비수도권 | 50% |
| 수도권 비과밀 | 25% |
| 수도권 과밀 | 적용 안됨 |

### 엔젤투자 소득공제 (조특법 §16)

| 투자금액 | 공제율 |
|---|---|
| 3,000만 이하 | **100%** |
| 3,000만~5,000만 | 70% |
| 5,000만 초과 | 30% |

한도: 종합소득금액 50%. 5년 이상 보유 시 양도세 비과세

### 벤처 스톡옵션 비과세 (조특법 §16의4)

- 연 2억 / 누적 5억 완전 비과세
- 부여 시점 벤처기업 확인 필수
- 시가 이하 발행 한도 직원당 20억 확대 (2026.1)

## G. ISA·연금저축·IRP

- ISA: 연 2,000만, 5년 1억 한도. 일반 200/서민 400 비과세, 의무 3년
- 연금저축+IRP: 합 900만 한도, 16.5%(5,500만 이하) / 13.2%(초과). 최대 환급 148.5만
- IRP 의무가입: 퇴직 시 자동 이체
- 연금 수령 (만 55세+가입 5년): 1,500만 이하 3.3~5.5% 분리
